# Git Workshop 2K26

A beginner-friendly repository created as part of the **Git Workshop 2K26** to learn and practice the basic concepts and commands of Git and GitHub.

## 📌 About

This repository contains the files and practice work completed during the Git Workshop. It is intended to demonstrate the basic usage of Git and GitHub for version control and collaborative software development.

## 🛠️ Topics Covered

* Introduction to Git and GitHub
* Creating a Git repository
* `git init`
* `git status`
* `git add`
* `git commit`
* `git push`
* `git pull`
* Git branches
* Merging
* Working with GitHub repositories
* Basic GitHub workflow

## 🎯 Purpose

The main purpose of this repository is to gain hands-on experience with Git and GitHub and understand how version control is used in software development.
